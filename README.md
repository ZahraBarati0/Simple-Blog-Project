# Simple Blog (React Router Demo)

A simple blog-style web application built with React and React Router.  
This project demonstrates routing, protected routes, URL parameters, and basic authentication logic.

---

## 🚀 Features

- React Router v6 routing
- Nested layouts
- Protected routes
- URL parameters (`/blog/:id`)
- Simulated authentication
- Programmatic navigation
- 404 Not Found page
- Clean custom dark theme with Bootstrap styling

---

## 📂 Pages

- Home
- Blog (list of posts)
- Blog Details (dynamic route)
- Login
- Dashboard (protected)
- Not Found (404)

---

## 🔐 Authentication

Authentication is simulated using React state.  
When logged in, users can access the protected Dashboard route.

---

## 🛠 Tech Stack

- React
- React Router DOM
- Bootstrap 5
- CSS Custom Theming

---

## 📦 Installation

```bash
npm install
npm run dev
```

---
## 📸 Purpose

This project was created to practice:

Client-side routing

Protected routes

Navigation with useNavigate

URL params with useParams

Layout structure in React
